# VULCA 0.24.2 Capability Hardening

**Status:** draft

## Problem

`v0.24.1` (tag `0f66cc7b`, PR #171) records the `vulca.capability` layer exactly
as vulca-platform has run it since 2026-08-14. Two independent reviews of that
branch on 2026-09-05 found defects that the platform's own gates cannot see
because they sit inside the capability boundary:

1. Provider failures are misfiled. `builtin.py` catches builtin
   `TimeoutError`/`ConnectionError` and the SDK boundary classes, but the
   OpenAI provider raises `httpx.TimeoutException`, `httpx.ConnectError` and
   `RuntimeError` (401/402/403/429/5xx). Those escape `invoke` as
   "capability programming error"; the manifests' `PROVIDER_TIMEOUT` and
   `PROVIDER_TRANSPORT_FAILED` codes are unreachable with the production
   provider, and the downstream retry taxonomy never fires.
2. Disclosure fields are laundered at the boundary. master (#169/#170) added
   `EvalResult.failed`, `.mock`, `.error` and `.cost_is_estimate`; the evaluate
   cell's `_evaluation_output` whitelist drops all four, so a crashed or mock
   evaluation projects as `SUCCEEDED` with a real-looking score, and a constant
   cost is reported as `costKnown: true`. The edit cell reports a literal
   `0.05` as known cost on both inpaint paths.
3. Image handling can crash the worker. `_resize_cover` scales the whole
   source before cropping, so extreme aspect ratios request tens of gigapixels;
   `PIL.Image.DecompressionBombError` derives from `Exception` and is outside
   every except tuple, so a crafted header aborts the invocation after payment.
4. The price schedule is not actually frozen. `get_openai_image_price_schedule`
   returns a shallow copy and the hash is computed once at import, so a mutated
   table passes the hash check; the dall-e-2 entry lists sizes that model never
   offered; the "maximum" estimate assumes one character per token.
5. Pre-flight failures report `SideEffectState.UNKNOWN` although no provider
   call was dispatched, which disables the platform's retry rule.

## Goal

Ship `v0.24.2` from master (which contains #171 plus #168–#170) with the five
defects above fixed, each pinned by a test that fails on `v0.24.1` and passes on
the fix, without changing the public names vulca-platform imports.

## Non-goals

- The model-controlled URL fetch in the chat-completions image path
  (pre-existing, tracked in draft advisory GHSA-53x5-r63m-j44g).
- Verifying the OpenAI price numbers against a live source (offline; only
  structural fixes here, the table stays marked as observed 2026-08-14).
- Making the contract dataclasses hashable or deep-immutable (API change,
  separate decision).
- Any change to the eight downstream names, their field order, or the six
  capability ids/versions.
- Bumping the vulca-platform lock; that is a platform milestone.

## Decisions

- Exception mapping lives in one place: a `_classify_provider_error(exc)`
  helper in `builtin.py` maps `httpx.TimeoutException` → `PROVIDER_TIMEOUT`,
  `httpx.TransportError`/`ConnectionError` → `PROVIDER_TRANSPORT_FAILED`,
  `httpx.HTTPStatusError` and provider `RuntimeError` with an HTTP status →
  `PROVIDER_REJECTED` (new code, documented in the manifests), everything else
  stays a programming error. Cells call it instead of enumerating types.
- `_evaluation_output` carries `failed`, `mock`, `error` and
  `cost_is_estimate` verbatim. A result with `failed=True` is a `FAILED`
  capability result (`EVALUATION_FAILED`), never `SUCCEEDED`; `mock=True`
  is surfaced in the output and the receipt. `cost_is_estimate=True` means
  `costKnown=False`. The edit cell reports `costKnown=False` whenever the cost
  is the fallback constant.
- `adapt_static` crops first (`ImageOps.fit` semantics) and enforces a
  `width * height` budget per request before decoding; `DecompressionBombError`
  joins the corrupt-artifact except tuples and maps to `CORRUPT_ARTIFACT`.
- The schedule is returned as a deep, read-only view (`MappingProxyType` over
  copied nested dicts) and the hash is computed over the live object on every
  check. dall-e-2 lists only 256/512/1024 squares. The estimator stops claiming
  an upper bound for prompts: it names its assumption in the estimate object.
- Pre-flight failure paths (before any provider call) report `NOT_STARTED`.
- Version `0.24.2`; CHANGELOG entry in the house format with the verification
  record.

## Acceptance criteria

- Each fix has a regression test that fails against `v0.24.1` (verified by
  running the new tests on a `v0.24.1` checkout) and passes on the fix.
- `python -m mypy src/vulca/capability`, the capability release gate,
  `tests/test_inpaint.py`, `tests/test_openai_price_schedule.py`,
  `tests/test_openai_provider.py` and `ruff check src/ tests/` pass locally and
  in CI on 3.11 and 3.12.
- `from vulca.capability import CapabilityArtifact, CapabilityInvocation,
  CapabilityManifest, CapabilityRegistry, CapabilityResult, CapabilityStatus,
  SideEffectState, builtin_registry` still works and field order is unchanged
  (existing contract-lock tests).
- Wheel builds reproducibly; `twine check` passes.
